## Purpose

Определяет, как `qwen-opsx-ui` устанавливается в Qwen Code как расширение и как включается его status line. Существующие настройки пользователя при этом не теряются, и их можно вернуть.

## ADDED Requirements

### Requirement: Установка как расширение Qwen Code
Проект SHALL устанавливаться командой `qwen extensions link <путь>` (локально) и `qwen extensions install <источник>` без шага сборки и без установки зависимостей. Манифест расширения MUST объявлять только хуки и файл контекста. Установка MUST NOT требовать ответов на вопросы о настройках. Расширение MUST NOT объявлять MCP-серверы и MUST NOT обращаться к сети.

#### Scenario: Локальная установка
- **WHEN** пользователь выполняет `qwen extensions link /path/to/openspec-ui` и перезапускает Qwen
- **THEN** расширение `qwen-opsx-ui` есть в `qwen extensions list`, и его хуки активны в новой сессии

#### Scenario: Без сети
- **WHEN** расширение работает в сессии
- **THEN** оно не открывает сетевых соединений

### Requirement: Включение status line
Расширение SHALL предоставлять команду установки status line. По умолчанию она прописывает в `.qwen/settings.json` текущего проекта настройку `ui.statusLine` типа `command` с обновлением раз в секунду и сохранением ANSI-цветов. С флагом `--user` настройка записывается в `~/.qwen/settings.json`. Остальные настройки файла MUST сохраняться без изменений. Повторный запуск MUST ничего не менять.

#### Scenario: Первая установка
- **WHEN** в `.qwen/settings.json` проекта нет `ui.statusLine`, и пользователь запускает команду установки
- **THEN** в файле появляется `ui.statusLine` расширения, а остальные ключи файла не меняются

#### Scenario: Повторный запуск
- **WHEN** status line расширения уже прописан, и пользователь снова запускает команду установки
- **THEN** файл не меняется, а команда сообщает, что всё уже настроено

### Requirement: Сохранение чужого status line
Если `ui.statusLine` уже задан командой, которая не принадлежит расширению, команда установки SHALL без флага `--force` ничего не менять и объяснить, как продолжить. С флагом `--force` прежняя команда MUST сохраняться и вызываться вне OpenSpec-флоу (см. `qwen-opsx-ui/status-line`). Флаг `--remove` MUST возвращать прежнее значение `ui.statusLine`, а если его не было — удалять ключ.

#### Scenario: Чужой status line без --force
- **WHEN** в настройках есть `ui.statusLine` с командой пользователя, и команда установки запущена без `--force`
- **THEN** настройки не меняются, а команда сообщает о конфликте и предлагает `--force`

#### Scenario: Чужой status line с --force
- **WHEN** команда установки запущена с `--force` поверх команды пользователя
- **THEN** прописан status line расширения, а прежняя команда сохранена как запасной вариант

#### Scenario: Удаление
- **WHEN** пользователь запускает команду установки с `--remove`
- **THEN** `ui.statusLine` возвращается к значению до установки

### Requirement: Проверка окружения
Команда установки SHALL проверять, что OpenSpec CLI доступен и что в проекте есть Qwen-команды OpenSpec (`.qwen/commands/opsx-*.md`). Для каждой найденной проблемы она MUST выводить предупреждение с командой исправления (например, `openspec init --tools qwen`). Сама команда установки MUST NOT запускать исправления.

#### Scenario: Нет opsx-команд для Qwen
- **WHEN** в проекте нет `.qwen/commands/opsx-propose.md`
- **THEN** команда установки предупреждает и предлагает `openspec init --tools qwen`, но сама её не запускает

### Requirement: Подсказка о незавершённой установке
Если расширение активно, а status line расширения не настроен ни в проекте, ни у пользователя, то в сессии в OpenSpec-проекте расширение SHALL один раз показать короткое сообщение с точной командой установки. Сообщение показывается по окончании первого хода сессии: Qwen 0.25 не выводит в ленту сообщения хука старта сессии. Сообщение MUST NOT повторяться в следующих сессиях этого проекта после первого показа. Если сессия закончилась раньше, чем сообщение было показано, оно MUST быть показано в следующей сессии.

#### Scenario: Первый запуск после установки расширения
- **WHEN** пользователь впервые стартует сессию Qwen в OpenSpec-проекте, где status line расширения не настроен, и агент заканчивает первый ход
- **THEN** в ленте появляется одно сообщение с командой установки status line

#### Scenario: Повторный запуск
- **WHEN** пользователь стартует следующую сессию в том же проекте, не настроив status line
- **THEN** сообщение не показывается
